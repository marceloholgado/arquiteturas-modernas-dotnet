Creating Envoriment
- Download Docker 
- Install rabbitmq `docker run -d -p 15672:15672 -p 5672:5672 rabbitmq:4.1-management`
- Install Keycloak Postgres for gateway authentication open Folder keycloack and run `docker compose up -d`
- Install the nuget packages necessary for each project, open the nuget package manager and select all project and click install.
